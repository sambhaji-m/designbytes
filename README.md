# Frontend Assignment

Tech Stack:
- Next.js
- React
- TypeScript
- Tailwind CSS
- Shadcn UI
- Recharts
- Lucide React

Local setup:

# npm install
# npm run dev

## Data / API

Dashboard mock data is stored in `src/data/dashboard.json`. A Next.js Route

Handler exposes it through `/api/dashboard`, and accident filters use the
`period` query parameter (`today`, `month`, or `year`). No external backend or
database is required.
